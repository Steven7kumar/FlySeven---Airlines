# FlySeven Airlines ✈️

## Project Overview
FlySeven Airlines is a fictional airline business analytics project.

The objective is to analyse airline operations, passenger bookings,
revenue performance and customer satisfaction.

## Business Objectives
- Analyse passenger booking trends.
- Monitor flight performance.
- Evaluate revenue and profitability.
- Identify high-performing routes.
- Understand customer satisfaction.

## Tools & Technologies
- Microsoft Excel
- SQL
- Power BI
- Git & GitHub
